# Orbiter - Layout Guidelines

> 画面レイアウトのルールブック

---

## レイアウト原則

### 1. コンテンツファースト
レイアウトはコンテンツの性質によって決まる。装飾ではなく、情報の構造を反映すべき。

### 2. レスポンシブ・バイ・デフォルト
すべてのレイアウトはモバイルファーストで設計し、ブレークポイントで段階的に拡張する。

### 3. 一貫したスペーシング
Orbiterの10x Scaleスペーシングトークンを使用する。マジックナンバー禁止。

---

## ブレークポイント

| 名前 | サイズ | 用途 |
|------|--------|------|
| `sm` | 640px | モバイル横向き |
| `md` | 768px | タブレット |
| `lg` | 1024px | デスクトップ |
| `xl` | 1280px | ワイドスクリーン |
| `2xl` | 1536px | 超ワイド |

---

## レイアウトパターン

### MasterDetail (マスター詳細)
**用途**: リストから選択して詳細を表示する画面
- モバイル: リストのみ表示 → タップで詳細に遷移
- デスクトップ: 左にリスト、右に詳細を並列表示

### Stacked (スタック)
**用途**: 情報を縦に積み上げる汎用レイアウト
- ダッシュボード、設定画面、フォーム画面に適用

### Sidebar (サイドバー)
**用途**: 常にナビゲーションを表示する画面
- モバイル: ハンバーガーメニュー → ドロワーで表示
- デスクトップ: 固定サイドバー

---

## 間隔ルール

| 場所 | トークン | 値 |
|------|---------|-----|
| ページ余白 | `orb-40` 〜 `orb-80` | 16px 〜 32px |
| セクション間 | `orb-60` 〜 `orb-80` | 24px 〜 32px |
| カード内余白 | `orb-30` 〜 `orb-40` | 12px 〜 16px |
| 要素間（密） | `orb-10` 〜 `orb-20` | 4px 〜 8px |
| 要素間（標準） | `orb-20` 〜 `orb-30` | 8px 〜 12px |
