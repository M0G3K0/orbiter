# 🧩 Phase 02: Spec Explore（仕様の探索）

要件に対して**複数パターンのWF + 仕様を一気に作成**し、
ダメな案を落として、良い案だけをPrototypeに渡す。

> 🔥 **AIの強み**: 人間が1案考える間にAIは3〜5案の仕様を出せる。

---

## 🔍 Step 1: パターンの探索（Fallback Chain）

要件を満たすインターフェースパターンを、**具体→汎用の順で探す。**

```
1️⃣  プロジェクト内の既存パターン        ← 最も具体的
    参照: 既存の画面、過去の spec

2️⃣  デザインシステムのパターン
    参照: DESIGN_SYSTEM_LIST.md
          METAPHOR_LIBRARY.md

3️⃣  一般的なUI原則                    ← 最も汎用的
    参照: マテリアルデザイン、HIG、NNGroup 等
```

---

## 📐 Step 2: 複数案の仕様作成

各パターンについて**WF + 仕様をセットで**作成する。

### 各案のテンプレート

```
### 🅰️ Pattern A: (パターン名)
> (1文でコンセプト)
> Fallback Level: (1️⃣ / 2️⃣ / 3️⃣)

#### ワイヤーフレーム
┌─────────────────────────────┐
│                             │
│   (ASCII WF)                │
│                             │
└─────────────────────────────┘

#### コンポーネント
| 区画 | コンポーネント | Props | 備考 |
|------|--------------|-------|------|

#### インタラクション
| トリガー | 何が起きる | 備考 |
|---------|-----------|------|

#### 状態 & エッジケース
| 状態 | 条件 | 表示内容 |
|------|------|---------|
| ✅ Default | | |
| 💀 Empty | | |
| ⏳ Loading | | |
| ❌ Error | | |

#### 画面遷移
(この画面の前後の流れ)

👍 良い点: ...
👎 トレードオフ: ...
```

🚪 **人間のゲート**: ユーザーと一緒にダメな案を落とす。

```
3案出しました。比較表を見てください。

🅰️ A: (名前) — (1文)
```
