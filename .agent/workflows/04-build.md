# 🔨 Phase 04: Build（本実装）

プロトタイプ検証で確定したパターンを、**本番コード**に仕上げる。

> ⚠️ プロトタイプ = 実装コードなので、**ゼロから書き直さない**。
> やることは「削る・整える・繋ぐ」。

---

## やること

### 1️⃣ 削る — 不要なバリアントの除去
- 採用されなかったバリアントの分岐コードを削除
- `?variant=` パラメータの処理を削除

### 2️⃣ 整える — コード品質の仕上げ
- Mock データを実データ / API 接続に置き換え
- エッジケース（Empty / Loading / Error）の実装を確認
- コンポーネントの Props を整理

### 3️⃣ 繋ぐ — 本番環境への統合
- ルーティングを本番の画面構成に統合
- dev tooling（Map/Spec/QA タブ）を除外（environment フラグ）
- `ng build` が通ることを確認

---

## ✅ 完了条件

- [ ] 不要なバリアント分岐が削除されている
- [ ] Mock データが実データに置き換わっている（またはAPI接続済み）
- [ ] エッジケース（Empty / Loading / Error）が実装されている
- [ ] ビルドが通る
- [ ] ユーザーが画面を確認できる状態
