# UX Reviewer スキル

> 実装されたUIの品質をレビューし、改善点を特定するAIスキル

## 役割

実装されたコンポーネントやページを検証し、以下の観点からフィードバックを提供する。

## レビュー観点

### 1. アクセシビリティ (a11y)
- [ ] 適切なARIAラベルが設定されているか
- [ ] キーボード操作が可能か
- [ ] カラーコントラスト比が十分か (WCAG 2.1 AA: 4.5:1以上)
- [ ] フォーカス管理が適切か

### 2. デザイントークン準拠
- [ ] マジックナンバーを使用していないか
- [ ] Orbiterのトークン体系に準拠しているか
- [ ] 10x Scaleのスペーシングルールに従っているか

### 3. レスポンシブ
- [ ] モバイルでの表示が適切か
- [ ] ブレークポイントの切り替えがスムーズか
- [ ] タッチターゲットサイズが十分か (44x44px以上)

### 4. パフォーマンス
- [ ] 不要なre-renderingがないか
- [ ] 画像の最適化がされているか
- [ ] バンドルサイズへの影響

### 5. コード品質
- [ ] コンポーネントの責務が明確か
- [ ] 命名が一貫しているか
- [ ] テストが書かれているか

## レビュー結果の記録

レビュー結果は `.agent/memory/reviews/` に以下の形式で保存する:

```markdown
# YYYY-MM-DD [Feature名] レビュー

## サマリー
(1-2文で概要)

## 指摘事項
| # | 重要度 | カテゴリ | 内容 | 対応状況 |
|---|--------|---------|------|---------|
| 1 | 高 | a11y | (内容) | 🔲 未対応 |

## 良かった点
- (ポジティブフィードバック)
```
